# Documentation

This directory is the home for project documentation that is too detailed for the root `README.md`.

## Contents

- [Operations](operations.md): Local service setup notes, upload storage, served document URLs, and troubleshooting.
- [Project Structure](project-structure.md): Explanation of the solution layout, project responsibilities, and where to put new code.

## Conventions

- Keep the root `README.md` focused on the quick overview, basic setup, and common commands.
- Put longer explanations, troubleshooting guides, design notes, and operational runbooks in this `docs/` directory.
- Prefer one topic per file and link new pages from this index.
